# wiki-tuku

Tuku's Wikipedia-Style Personal Webpage

This project is a Wikipedia-style personal webpage built using HTML and CSS, customized for Tuku. It serves as a digital profile that showcases personal details, education, profession, interests, and social media links in a structured format.

Features:

✔️ Wikipedia-like layout with sidebar navigation
✔️ Well-structured sections: Early Life, Education, Personal Life, Creative Works
✔️ Responsive design with a clean, minimalist UI
✔️ Personal branding with social media and GitHub links

Technologies Used:

HTML5 for content structure

CSS3 for styling and responsiveness


How to Use:

1. Download or clone this repository.


2. Open wiki-tuku.html in a browser.


3. Customize the details in the HTML file if needed!
